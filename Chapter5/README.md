## 東京科学大学（旧・東京医科歯科大学）のオリジナルの版との違い
トップのREADME.mdにも記載していますが、新潟大学大学院医歯学総合研究科　顎顔面放射線学分野　での学生演習用としてオリジナルの版からローカル環境での実行するように改訂しています。<br>
## 用語の統一と表記の変更
### テキスト内の「（COVID-19による）肺炎」を「COVID」へと統一
テキスト内では「肺炎」と「正常」の判別とありますが、用いているサンプル画像は「COVID-19による肺炎の胸部X線画像」です。したがって「（一般的な）肺炎の胸部X線画像」というカテゴリー（ドメイン）のサブカテゴリー（サブドメイン）となっています。このため、内挿・外挿・適応範囲外の観点、および汎化性能の観点からテキスト内の「（COVID-19による）肺炎」を「COVID」へと統一しました。
### 「肺のX線画像を用いた」を「肺のX線画像のサンプルを用いた」に統一
テキスト内ではデータ数の問題や上記のカテゴリー（ドメイン）の問題、さらにはオリジナルからの圧縮画像という画像サイズの問題による影響について十分には触れられてはいないため、誤解を防ぐ目的で「肺のX線画像を用いた」を「肺のX線画像のサンプルを用いた」に統一しました。
