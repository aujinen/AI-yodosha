### windowsの場合
直下の３つのフォルダ以下を```C:\Users\[ユーザ名]\nncd_bucket\datasets```直下にコピーする。
各フォルダ内のindex.csvの内容に従って、dataフォルダ内にハードリンクを埋め込む。
変換ソフトは後日アップロード

### Linuxの場合
直下の３つのフォルダ以下を```/home[ユーザ名]/nncd_bucket/datasets```直下にコピーする。
各フォルダ内の```index.csv```の改行コードを```nkf -d index.csv```にて変換する。
さらに、下記のコマンドでパス区切りのバックスラッシュをスラッシュに変換する。
```sed -i 's|\\|/|g' index.csv```
各フォルダ内のindex.csvの内容に従って、dataフォルダ内にハードリンクを埋め込む。
変換ソフトは後日アップロード
